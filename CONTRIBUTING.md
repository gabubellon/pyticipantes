# Contribuindo

Contribuições são bem-vindas! Abra uma issue ou um pull request.

## Licença das contribuições

O projeto é distribuído sob a [AGPL-3.0](LICENSE) e também sob [licença comercial](COMMERCIAL.md).
Para que isso seja possível, ao enviar uma contribuição você concorda que:

1. você tem o direito de enviá-la, e ela é sua autoria;
2. ela é licenciada sob a AGPL-3.0 **e** você concede ao mantenedor (Gabu Bellon) o direito de
   redistribuí-la também sob outras licenças, incluindo a comercial.

Se não concorda com isso, abra uma issue em vez de um pull request.

## Antes de enviar

```bash
make lint
make test
```
