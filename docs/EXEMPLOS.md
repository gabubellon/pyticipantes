# Exemplos para teste

Quer experimentar antes de usar seus dados? Baixe os dois arquivos abaixo.

| Arquivo | Para quê |
|---|---|
| [exemplo.csv](downloads/exemplo.csv) | Planilha com 3 participantes fictícios (passo 1) |
| [fundo-exemplo.png](downloads/fundo-exemplo.png) | Imagem de fundo do certificado (passo 2) |

## Como testar

1. Abra o app e clique em **+ Novo**. O certificado já nasce com esses dois arquivos.
2. Ou, em um certificado existente: envie `exemplo.csv` no passo 1 e `fundo-exemplo.png` no passo 2.
3. Veja a prévia, gere com **Apenas os 1 primeiros** e abra o PDF.
4. Para testar o e-mail, troque os e-mails do CSV pelo seu próprio.

## Colunas da planilha de exemplo

`nome`, `email`, `evento`, `data`, `hora`, `local`. Veja [Campos e filtros](CAMPOS.md) para usá-las nos textos.

Os arquivos também estão no repositório, na pasta `src/pyticipantes/exemplos/`.
